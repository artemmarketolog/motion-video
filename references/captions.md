# Субтитры

Модуль `scripts/mvcaptions.py`. Текст = утверждённый сценарий: слова и тайминги приходят от ElevenLabs
вместе с озвучкой (`voice.py` → `work/voice.words.json`), распознавание речи не нужно.

```python
from mvcaptions import Captions, load_words
words = load_words('work/voice.words.json', delay=0.3)          # delay = где голос начинается в ролике
cap = Captions(c, words, style='pop', font='Montserrat', weight=900, size=80, case='upper',
               color='#fff', accent='#ffd400', y=.65)
cap.hide(t0, t1)          # перебивка занимает кадр: субтитры уходят
cap.place(t0, t1, y=.3)   # в этом кадре лицо внизу: поднять
cap.build()
```
В шаблоне `footage-ad` то же задаётся в `creative.json` (`captions`, `caption_zones`); перебивки сами
вызывают `hide`. Стиль клиента по умолчанию берётся из `<studio>/clients.json` (`overrides`: font, fontsize,
text_case, highlight_color, pos, highlight).

## Шесть стилей

| Стиль | Как выглядит | Когда |
|---|---|---|
| `pop` | фраза целиком, звучащее слово цветом (+ лёгкий толчок, `bump`) | реклама по умолчанию, преемственность со старыми креативами |
| `karaoke` | фраза приглушена, слово заливается цветом слева направо по ходу речи | сторителлинг, отзывы, спокойнее pop |
| `word` | одно слово за раз, крупно по центру, в ритм | динамичные ролики, хук первых секунд |
| `calm` | фраза проявляется целиком (blur-in), обычный регистр, без подсветки слов | презентации, объясняющие ролики, премиум |
| `pill` | фраза на скруглённой плашке, слова появляются по мере речи | шумный фон, светлая съёмка, «интерфейсный» стиль |
| `accent` | фраза целиком, светятся и растут только ключевые слова (цифры и `keywords=`) | когда важна одна цифра или выгода |

Из официального каталога HyperFrames (~40 «идентичностей» субтитров) взяты принципы разбивки и эти
жанры; игровые (arcade, 8-бит, vhs) не берём. Справочник:
`references/upstream/embedded-captions/CATALOG.md`.

## Разбивка на фразы и строки (как у монтажёра)

1. Смысловые границы: пауза ≥ 0,45 с, конец предложения `. ! ?`, двоеточие, запятая с паузой ≥ 0,25 с.
2. Если кусок не помещается в 2 строки (ширина меряется по реальному файлу шрифта через Pillow,
   `font_file=`; в `footage-ad` подставляется сам), кегль этой фразы уменьшается до −12 %; не помогло —
   кусок делится пополам по времени, предпочтительно на запятой.
3. Служебные слова («не», «до», «от», «и», «в», «на», «когда»…) не остаются в конце фразы или строки,
   числа («19 990», «39 000») не рвутся.
4. Две строки выравниваются по ширине. Фразы короче 0,5 с сливаются с соседней, если влезают.
5. Короткие паузы (< 0,35 с) мостятся — текст не мигает; хвостовые запятые убираются, в капсе без точки.
6. Перебивка закрыла начало предложения — продолжение этого предложения тоже не показывается
   (перебивка уже несёт эту мысль); следующее предложение появляется сразу после перебивки.

Без файла шрифта работает грубая оценка по числу знаков — для клиентских шрифтов всегда давай файл.

## Где ставить

- `y` — центр блока субтитров, доля высоты (как `--pos` старого конвейера). 9:16 по умолчанию 0,65;
  с плашками — между ними (например 0,575 при плашках сверху и снизу). Не ниже нижнего безопасного поля (240 px в 9:16).
- Лицо, товар или надпись в зоне субтитров → `caption_zones`/`place` на время этого кадра.
  Подсказка — `on_screen`/`plan` в `shots_catalog.json`.
- Перебивки, карточки на весь кадр → субтитры скрыты (`hide`), голос продолжается.
- Проверка: `frames.py` на середине каждой фразы у стыков и на перебивках; `check` ловит перекрытия и контраст.
