# Кейс: «Одна кнопка» (премиум, предмет-герой, 9:16, 16 с)

Реклама курса для детей «создай игру с ИИ». Заказчик отметил ролик как эталон необычного формата.
Это второй эталон предмета-героя после [hero-object-wheel](hero-object-wheel.md): тот же подход (физика → кривая →
звук из той же функции), другой предмет и другая драматургия. Не копировать клавиатуру в лоб, брать метод.

Идея: предмет, ассоциированный с темой (ИИ → запрос → клавиатура), и одно главное действие (удар ENTER),
после которого предмет превращается в результат (кейкапы становятся платформами игры).

Что делает его дорогим:
- клавиатура в настоящем CSS 3D: кейкап = усечённая пирамида (верх + скошенные грани), камера = три вложенных
  слоя с перспективой, глубина резкости = у каждого ряда клавиш своя сцена с blur, свет затухает к краям;
- вся механика считается в Python и уходит в GSAP сэмплированными кривыми (60 Гц) в `ease` одного твина:
  ход клавиш (пружина с преднатягом, упор, отскок), камера (сплайн + один рывок), полёт кейкапов, прыжки героя
  (баллистика); буква запроса появляется в момент упора клавиши;
- щелчки печати синтезированы из той же функции хода (удар об упор и возврат, громкость от скорости), онсеты
  совпадают с ударами по кадру (медиана 0,1 мс);
- подъезд камеры к жёлтому ENTER в тишине музыки, удар ENTER ровно на первом ударе дропа, световая волна под
  клавишами и единственный резкий рывок камеры за весь ролик;
- оффер живёт в том же мире: цифры возраста и длительности на кейкапах, финальный ENTER с надписью «Записаться»
  нажимает герой на словах призыва.

Грабли и решения:
- без звука первые 3 с были пустыми (размытая клавиатура, мелкая строка) — добавлены крупные титры
  «ОДНА ФРАЗА… / ОДНА КНОПКА…» 118–128 px с первого кадра, строка запроса 70 px, резкость за 0,6 с;
- после дропа между титром и героями висела пустая тёмная полоса — титры опущены на 640–1000 px, героев
  проверять на зазор с титрами по проекции камеры;
- полного бита в сгенерированном треке хватило на 2 такта: недостающее добрано повтором такта на сетке
  (8.10, 10.50, 12.90 с), а не вторым куском с баса; дроп брать по онсету удара (9.946), не по басу (10.00);
- голос ElevenLabs тихий: музыка −18,5 dB при голосе +4, иначе она всего на 5–7 dB под голосом.

Цена: ~2 ч работы агента, 4 сборки; полный рендер тяжёлой 3D-сцены 17–21 мин на 6 ядрах, держать не больше двух
рендеров одновременно.
