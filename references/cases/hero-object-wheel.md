# Кейс: «Слышишь?» (премиум, предмет-герой, 9:16, 12,6 с)

Реклама акции «колесо подарков» для beauty-студии. Заказчик назвал ролик эталоном **качества** серии:
музыка, цвет, звук, монтаж. Это не шаблон стиля для других роликов, а планка.

Что делает его дорогим:
- один объект, темнота, свет только в `screen`; неподвижные блики на вращающемся колесе;
- глубина резкости двумя копиями слоя + маска с CSS-переменными, rack focus в начале, расфокус в финале;
- непрерывная камера `sine`, одна резкая точка `expo.out` на дропе (4,56 с);
- вращение колеса считается в Python и передаётся кривой в `ease` одного твина (без onUpdate);
- щелчки синтезированы из той же функции, что и язычок (45 щелчков, онсеты ±2 мс) — `sfx.py` (`flap_and_ticks`);
- тишина в музыке перед дропом, последний щелчок ровно на дропе, лампы на реальных ударах 808;
- текст мало двигается: blur-in, небольшой подъём, блик по золоту; зерно .13 overlay.

Цена: 3–5 ч работы агента, первая сборка ~7 мин на `mv.py` (одним куском было ~11 мин), правка титра 63 с.
Шаблон `blank` описывает, как начать такой ролик с нуля.
