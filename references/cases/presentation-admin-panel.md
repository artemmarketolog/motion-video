# Кейс: «Действующая панель» (презентация 16:9, 60 с)

Анимированная презентация реальной админ-панели для заказчика. Тот же сториборд собран на Remotion и на
HyperFrames для сравнения движков.

- Реальная админка показана 13 снятыми состояниями интерфейса: монтаж с курсором, приближениями, подсветками.
  Интерфейс и метрики не дорисовывались — только реальные скриншоты.
- Диктор — спокойный мужской голос (`narrator`), общий микс −16 LUFS, звук собран отдельно и наложен копией видеопотока.
- Рендер: Remotion 4 мин 43 с (6 сцен, concurrency 2), HyperFrames 6 мин 32 с одним куском в 1 воркер.
  С `mv.py` (3 воркера, сцены-куски) быстрее, а правка одной сцены занимает 1–2 мин.
- Для презентаций это образец темпа: смена мысли 4–8 с, одна функция за такт, спокойные входы.
