# Режиссура: почему дорого, а не «анимированные слайды»

Сначала смысл и визуальный язык, потом код. Каждое движение что-то утверждает о предмете:
вылет справа = «пришло откуда-то», перелёт с возвратом = «у этого есть масса», медленный тяжёлый вход =
«это важно». Проверка: назови, что значит движение, предложением, которое заканчивается
(«счётчик дышит, потому что данные ещё идут»). Не получается — убери движение.

Четыре честные работы движения: направить внимание, связать моменты, показать изменение,
передать характер бренда. Движение без работы = декорация, а декорация читается как дёшево.
Когда кадр кажется мёртвым, не добавляй амплитуду: найди одну вещь, которая реально меняется, и дай ей нести кадр.

## Восемь правил (HyperFrames «Motion that reads premium», проверено на наших роликах)

1. **Ничего не останавливается полностью.** На удержании остаётся тихая жизнь: дыхание 1–2 %,
   медленный дрейф, блик. Замерший последний кадр — главный признак дешёвого моушена.
2. **Камера — действующее лицо.** Одно непрерывное движение на сцену (наезд 4–8 %, панорама, параллакс),
   не затухающее в ноль к концу сцены.
3. **Перекрытие действий.** Два элемента не стартуют и не заканчивают одновременно. Шаг сдвига
   заметно короче самой анимации; фокусный элемент не ждёт, задерживаются вспомогательные.
   Разносить по времени то, что происходит, а не то, что уже было на месте.
4. **Составные свойства только для одной мысли.** Подъём + проявление = «прибывает». Подъём + поворот +
   масштаб + размытие = четыре разные мысли, текст нечитаем в полёте. Входы `ease out`, выходы `ease in`,
   перемещения по кадру `in-out`, удары `in`.
5. **Перелёт и запаздывание.** Перелёт (`back.out`) = масса; тень и корпус догоняют на кадр позже.
   Только для трансформаций: число никогда не перелетает своё значение.
6. **Планы глубины.** Дальний план движется медленнее камеры (×0,2), контент ×1, передний план быстрее (×3–6).
   Лучший признак глубины — перекрытие: один крупный размытый элемент проходит перед контентом.
7. **Темп по жанру.** Шоурил 1,5–4 с на мысль; презентация 4–8 с; реклама 9:16 — по голосу, одна мысль на фразу.
8. **Рукотворность воспроизводима.** Стоп-моушен = детерминированный PRNG с зерном + удержание по
   **номеру кадра** (`Math.floor(Math.round(t*fps)/2)`), не по секундам: время сика не ложится точно на 1/fps.

## Как не получить слайд-шоу

Слайд-шоу = независимые сцены + одинаковая энергия. Нужны оба свойства:
1. **Что-то переходит через границу сцены**: общий объект, пространство, линия, фон, фраза голоса.
   Способы: непрерывная камера по одному миру; склейка по форме/цвету/вектору движения; герой-предмет,
   который остаётся в кадре; постоянная рамка (интерфейс, линейка); звук как хребет (фраза или нота через склейку).
2. **Энергия меняется**: тишина, на фоне которой главный момент работает. Пауза в музыке перед дропом,
   остановка камеры на 1,5–2,5 с на главной мысли (при этом мир в кадре продолжает жить).

## Уровни «дорого» (что добавлять по уровню)

- Простой: чистая композиция, одно появление текста, ровный фон бренда, никакой суеты.
- Средний: blur-in по словам голоса, виньетка, лёгкое зерно, одно световое событие на сцену, мягкая камера.
- Премиум: свет физически правдоподобен (неподвижные блики на вращающемся объекте), глубина резкости,
  rack focus, одна резкая точка на всю вещь, звук из той же функции, что и движение. Разбор: [cases/hero-object-wheel.md](cases/hero-object-wheel.md).

## Чего избегать (набито на реальных правках)

- «Детская видеоигра»: мультяшность, конфетти-взрывы, писки, игрушечные колокольчики, 8-бит.
- Дешёвая динамика: много быстрых эффектов одновременно, bounce на всём подряд, несколько звуков в одну долю.
- Фото в брендовом дуотоне (розовая перекраска фотографий студии — «страшно, непрезентабельно»).
  Фото либо в натуральном цвете, либо ролик без фото.
- Фото-вставки, которые ломают логику (крем, сертификат на колесе без подписей сектора): каждая вставка
  должна объяснять то, что уже есть в кадре.
- Колесо/объект без подписей, когда смысл в том, что на нём написано.
- Текст с тире-подпорками, центр без иерархии, больше двух строк подряд на экране.
- Показ URL на экране, если клиент против; голосом «жми на ссылку» можно.
- Обрезанный сверху указатель/ключевой объект; стробоскоп (вращение быстрее ~11°/кадр при шаге 30°).
- Прогресс-бар или любая величина, зависящая от общей длины ролика (ломает кэш правок).
