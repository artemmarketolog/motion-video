# Монтаж из отснятых клипов (реклама из банка кадров)

Шаблон `footage-ad`: съёмка, голос, субтитры, плашки и моушен-перебивки в одной композиции
HyperFrames, с кэшем правок. Подготовка материала — банк кадров, каталоги, сценарии.

## Где что лежит (папка студии `MOTION_VIDEO_STUDIO`, по умолчанию `~/video-studio`)

| Путь | Что |
|---|---|
| `<studio>/clients.json` | реестр клиентов: голос, папка Drive, стиль субтитров (`overrides`: font, fontsize, text_case, highlight_color, pos, seg_len, zoom) |
| `<studio>/sources/<slug>/` | исходные клипы, `clips_catalog.json`, сценарии `scenario_*.txt`, **`scenarios-log.md`** (заходы и метрики) |
| `<studio>/shots/<slug>/` | банк кадров-атомов + `shots_catalog.json` (desc, subjects, beat, plan, location, on_screen) |
| `<studio>/music/` + `levels.json` | музыка и громкость по треку (`{"track.mp3": -25, "default": -25}`) |
| `<studio>/fonts/` | фирменные шрифты клиентов (проверяйте лицензию); общие OFL-шрифты лежат в `assets/fonts` скилла |
| `<studio>/projects/footage-<client>-<name>-<date>/` | папка ролика |

Скрипты подготовки: `scripts/footage/` (`download_gdrive.py`, `compress_media.py`,
`prepare_shots.py`, `merge_shot_meta.py`, `upload_gdrive.py`, `md2gdoc.py`). Методика банка и подписей:
[footage-bank.md](footage-bank.md). Как писать ТЗ на генерацию кадров: [footage-shot-prompts.md](footage-shot-prompts.md).

## Порядок

1. **Сценарий.** Сначала `sources/<slug>/scenarios-log.md`: что заходило у клиента (крючок, CPL, вердикт).
   Сценарий каждый раз новый, по [copy.md](copy.md) (структуры, хук, «личная история»), без длинного
   тире, проверка на признаки ИИ. **Утверждает пользователь** до монтажа.
2. **Банк кадров** (если нового материала нет, берётся готовый): скачать → сжать → каталог клипов
   (агенты с доступом к картинкам, параллельно) → `prepare_shots.py --max-seg 4` → подписи кадров → `merge_shot_meta.py`.
   Подробно: [footage-onboarding.md](footage-onboarding.md).
3. **Проект:** `new_project.py <studio>/projects/footage-<client>-<name>-<date> --template footage-ad --format 9:16`.
   Форматы: 9:16 (Reels/Stories, родной для банка), 4:5, 3:4, 1:1 (центр кадра), 16:9 (вертикальная
   съёмка по центру поверх своей размытой копии, `fit: "blur"`; можно `"fit": "cover"` для горизонтальной съёмки).
   В шаблоне лежит пример `creative.json` (кофейня) — замени данные на свои.
4. **creative.json** (единственное, что правится):
   - `client` — slug из `<studio>/clients.json` (голос, шрифт, цвет подсветки, высота субтитров, длина кадра, zoom);
   - `shots_dir`, `edl` — кадры по смыслу фраз (`{"shot": "...", "len": 2.4, "from": 0.5}`), клип не подряд сам за собой;
   - `voice` — `{"script": "work/script.txt", "voice": "narrator", "tempo": 1.15}` (новая озвучка, платно, кэш)
     или `{"mp3": ..., "words": ..., "tempo": 1.15}` (уже утверждённый дубль);
   - `music` — файл, `gain_db` (по умолчанию `levels.json` + 6 dB, потому что работает carve), `carve` 0.5;
   - `captions` — стиль и поправки ([captions.md](captions.md)), `caption_zones` — где поднять/опустить;
   - `inserts` — моушен-перебивки ([inserts.md](inserts.md)), `at_word` = на каком слове голоса;
   - `bars`, `cards` — плашки и карточки; `zoom` (1.06 против водяного знака, 1.0 если его нет), `drift` (медленный наезд 3 %).
5. `python3 build.py` → `hf.py check` → `mv.py build -o output/master-r1.mp4 --note "..."`.
6. `qa.py`, `frames.py` на субтитрах и перебивках, запись в `scenarios-log.md` (сценарий, дата, «ждёт утверждения»).
7. Выдача: ссылка на мастер; Google Drive (по желанию) — `scripts/footage/upload_gdrive.py` в папку клиента из `clients.json`.

## Ритм и синхрон

- Кадр меняется каждые ≤ 3 с (`seg_len` из реестра), показывает то, что звучит.
- Длина ролика = конец последнего слова + `tail` (0,6 с). Если кадров больше, лишние убираются из
  середины (начало и финал сохраняются); если меньше — сборка остановится и попросит кадры.
- Точный синхрон «кадр под фразу»: ставь `len` у кадров по таймингам слов (`work/voice.words.json`),
  метод из старого конвейера: [footage-bank.md](footage-bank.md) → «синхрон».
- Каждая смена кадра — якорь кэша. Заменить кадр, поправить субтитр в одной фразе или перебивку —
  перерисовывается только эта часть. Громкость, музыка — `mv.py audio` за секунды.

## Скорость (замеры на сервере 6 ядер, 3 воркера, качество `standard`)

| Действие | ролик 28,6 с (перебивки с размытием) | ролик 19 с (плашки) |
|---|---|---|
| Первая сборка | 6,4 мин | 4,5 мин |
| Замена одного кадра | 1,5 мин (1 кусок из 10) | — |
| Громкость музыки / микс | 18 с, картинка не рендерится | — |
| Правка, затрагивающая весь ролик (стиль субтитров) | полная сборка | полная сборка |

Простой ffmpeg-монтаж собрал бы креатив за 1–1,5 мин, но без моушен-перебивок, анимированных субтитров
и кэша правок. Размытие под перебивками (`backdrop-filter`) — самая дорогая часть кадра.
