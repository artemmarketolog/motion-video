# Типы роликов

Форматы (все шаблоны умеют каждый): 9:16 Reels/Stories, 4:5 и 3:4 лента Instagram, 1:1, 16:9 —
размеры и безопасные поля в [typography.md](typography.md).

Движок везде HyperFrames. Шаблон даёт скелет `build.py`, стиль берётся из бренда и брифа.
В брифе обязательна строка «чем этот ролик отличается от предыдущих».

| Тип | Шаблон | Уровень по умолчанию | Темп | Звук | Якоря кэша |
|---|---|---|---|---|---|
| Реклама из отснятых клипов / банка кадров 9:16, 15–40 с | `footage-ad` ([footage.md](footage.md)) | средний | кадр ≤ 3 с под фразу | голос ×1,15, музыка с carve, SFX перебивок | сетка 2–3 с от нуля |
| Презентация / объясняющий 16:9, диктор, 30–120 с | `explainer` | средний | спокойный: смена мысли 4–8 с, вход 0,4–0,7 с | диктор, тихая музыка (−22 dB, carve), редкие мягкие SFX (`cloth`, `soft_hit`, `tick`) | каждая сцена |

## Коротко по каждому типу

**Презентация (explainer).** Одна мысль на сцену; заголовок сцены и 1–3 опоры, не абзацы. Камера
почти стоит (1,00 → 1,03), движение даёт появление опор на словах диктора. Переходы мягкие (0,35 с),
между сценами общий фон/сетка, чтобы не выглядело слайд-шоу. Спокойный диктор (`narrator`) или голос клиента.
Длинные презентации: по одному файлу озвучки на сцену (правка сцены = новая озвучка только её).
Живой интерфейс показывай снимками реального продукта (кейс [presentation-admin-panel](cases/presentation-admin-panel.md)), не рисуй.

**Промо продукта.** Узнаваемый экран, одна функция за такт, камера ведёт внимание (наезд на кнопку,
подсветка). Показывай причину и следствие действия, а не хаотичное движение интерфейса.

**Предмет крупно (премиум).** Один объект, темнота и свет, непрерывная камера, одно резкое движение
на дропе, звук из механики объекта. Это долго (3–5 ч) и оправдано только для главного ролика.

**Кинетическая типографика.** Короткие фразы, склейка на долю, у каждой карточки свой вход (slam,
side, rise, mask), один герой-кадр с акцентным цветом. Ничего не замирает: медленный дрейф на удержании.

**Чат / UI.** Пузырь появляется после «печатает…», новые сообщения сдвигают ленту, камера медленно
въезжает в телефон; звук интерфейса на тех же временах. Реалистичные аватары без проф. грима
(image-gen), никаких эмодзи-шрифтов (их нет в рендере).

**Фото / editorial.** Фото в натуральном цвете (не перекрашивать в дуотон бренда), медленный наезд
или панорама 3–6 %, serif-заголовок + мелкая подпись, бумажные и затворные фоли. Генерация фото:
скилл `image-gen` (`batch_generate.py`), по одному промпту на кадр, файлы в `assets/photos/`.
