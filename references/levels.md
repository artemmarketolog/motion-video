# Уровни проработки

Уровень задаёт объём работы: число приёмов, проверок, время агента и деньги. Темп и стиль задаются
отдельно: бывает спокойный премиум (медленная камера, глубина резкости, тихая музыка) и быстрый простой ролик.

## Как выбрать

1. **Явно из запроса.** «быстро», «набросок», «черновик», «для себя», «внутреннее», «к вечеру» → простой.
   «премиум», «как 05», «дорого», «вау», «эталон», «главный ролик кампании» → премиум.
   Уровень из брифа серии обязателен для всех её роликов.
2. **По типу ролика** (колонка в [formats.md](formats.md)). Обычно средний.
3. **Спросить одним вопросом** только если премиум заметно меняет бюджет или срок (несколько платных
   дублей музыки, рендер дольше 30 мин). Вопрос с тремя вариантами, временем и ценой каждого.
   Всё остальное решай сам и называй выбранный уровень в первом сообщении.
4. Уровень поднимается правкой («сделай дороже») без переделки: средний строится так, чтобы
   премиальные слои добавлялись сверху (свет, глубина резкости, зерно, SFX из функции движения).

## Что входит

| | Простой | Средний | Премиум |
|---|---|---|---|
| Для чего | внутренние ролики, быстрые тесты гипотез, объяснение клиенту | рекламные креативы и внешние презентации по умолчанию | главный ролик кампании, эталон серии, бренд-видео |
| Текст | 1 шрифт, 2 веса, одно появление (fade + подъём 20 px, 0,45 с) | blur-in (10 px → 0, 0,5 с), вход на слове голоса (0–0,05 с раньше), пары строк с иерархией, скримы | + металл/золото с бликом, свечение на обёртке, удар ключевой цифры на акценте |
| Свет и фактура | ровный фон бренда или мягкий градиент | виньетка, зерно 0,05–0,08, 1–2 световых приёма (блик по объекту, мягкая вспышка) | зерно ~0,12 overlay, боке, глубина резкости двумя слоями, rack focus, световые пролёты, свет только в `screen` |
| Камера | нет или наезд 1,00 → 1,03 на сцену | плавные наезды и панорамы, одно акцентное движение на ключевой фразе | непрерывная камера, «вдох» и удар `expo.out` на акценте, крен ±1–3°, камера не стоит |
| Музыка | готовый трек или одна генерация, fade in/out | генерация под ролик, акцент на ключевой фразе через offset (`music.py analyze`) | 1–3 дубля, пауза перед дропом, акценты на реальных ударах |
| SFX | 0–3 пресета (whoosh на смену сцены, мягкий удар на финале) | 5–15 пресетов из `events.json` | синтез из той же функции, что и движение; ранние отражения; громкость по драматургии |
| Микс | голос + музыка, loudnorm −14 (реклама) / −16 (презентации) | + SFX, вырез частот музыки под голос (`carve`) | + баланс SFX по сценам, проверка онсетов ±1 кадр |
| Проверки | `check` + 3–5 кадров + `qa.py` | + кадры на всех событиях, контактный лист, `audiocheck.py`, таблица «текст/слово» | + художественный проход по [direction.md](direction.md), кадры ±1 у событий и стыков |
| Циклов доводки | 1 | 2 | 3+ |
| Время агента (12–15 с, 9:16) | 20–40 мин | 1–2 ч | 3–5 ч |
| Первая сборка (замер, 3 воркера) | ~1 мин | 2–4 мин | ~7 мин (05, 12,6 с) |
| Платные вызовы | TTS (+1 музыка) | TTS + 1 музыка (+ картинки) | TTS + 1–3 музыки + картинки |

Презентация 16:9 на 23 с среднего уровня собирается с нуля за ~3,5 мин, 60 с ≈ 7–9 мин.

## Для всех уровней

Запреты клиента, проверка текста на признаки ИИ ([copy.md](copy.md)), безопасные поля, текст совпадает
с голосом, честная строка «на слух не прослушано», мастер не перезаписывается.
