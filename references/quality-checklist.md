# Проверки

## Всегда

- `hf.py /ABS/VIDEO check --json --snapshots`: `ok: true`. Предупреждение `nested_structure_needs_subcomposition`
  у монолитной сцены безвредно. Любые `error` (перекрытие текста, текст под непрозрачным слоем, контраст)
  исправляй вёрсткой; `data-layout-allow-overlap` — только на конкретный текстовый блок, который
  намеренно участвует в наслоении, не на обёртку сцены.
- Кадры `snapshots/` и контактный лист `qa.py` просмотрены глазами (одним листом, не по одному:
  каждая картинка пересылает весь контекст).
- `qa.py master.mp4 --spec video-spec.json --out qa/rN`: полный декод, кодек, размер, fps, число кадров, звук.
- Проверка текста на признаки ИИ ([copy.md](copy.md)), запреты клиента, безопасные поля.
- Речь готового мастера (если есть голос): `voice.py asr output/master-rN.mp4 --text work/script.txt`
  (платно, копейки; mp4 принимается напрямую, аудиотеги и «60»/«шестьдесят» не считаются пропуском).
- Баланс голос/музыка по замеру `mv.py` в целевом коридоре [mix.md](mix.md); размер мастера < 100 МБ ([delivery.md](delivery.md)).
- Честная строка о звуке: «на слух не прослушано», если никто не слушал.

## Средний уровень

+ кадры на всех событиях (`frames.py --events events.json`), таблица «текст на экране ↔ слово голоса»,
  `audiocheck.py` (онсеты ±20 мс, LUFS, true peak).

## Премиум

+ художественный проход по [direction.md](direction.md): открывающий кадр → главное действие → стыки →
  финал; кадры ±1 вокруг событий и стыков (`frames.py --around`); сверка онсетов ~2 мс;
  нет ли стробоскопа, обрезанного объекта, замершего финала.

## После правки

`mv.py seams` (стыки перерисованных кусков), `frames.py` на правленом месте, `qa.py` нового мастера.
Для правки звука: хеш видеопотока совпал (mv.py проверяет сам), `audiocheck.py`.

## Записи в папке ролика

- `edits.jsonl` — пишет `mv.py` сам: время, файл, sha256, `--note`, что перерендерено, сколько заняло.
- `review.json` — пишет агент: `master`, `sha256`, формат, просмотренные таймкоды, источники
  (голос, музыка + промпт, фото + промпты/лицензии), ограничения проверки (например, «на слух не прослушано»).
