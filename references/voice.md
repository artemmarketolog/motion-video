# Голос

Ядро озвучки — отдельный скилл [elevenlabs-voice](https://github.com/artemmarketolog/elevenlabs-voice) (модель по умолчанию Eleven v4, v3 запасная;
личный реестр голосов, audio-теги, IPA для брендов). motion-video вызывает его через `scripts/voice.py`: ищет папку
`elevenlabs-voice` рядом с собой или по `ELEVENLABS_VOICE_SKILL`.

`voice.py tts --voice narrator --file work/script.txt --tempo 1.15 --out work/voice.wav [--take 1] [--dry-run]`
- Кэш по точному тексту + голосу + настройкам + дублю: повтор той же команды бесплатный.
  Новый дубль только осознанно через `--take 2`. Неясный результат = `unknown_billed`, без автоповтора.
- `--tempo` ускоряет готовый файл (`atempo`), тайминги слов в `voice.words.json` уже поделены на темп.
  Реклама в Reels/Stories: живой голос ×1,15. Презентации: спокойный диктор (`narrator`) без ускорения.
- Для длинных презентаций: один файл сценария на сцену (`work/script-s3.txt`). Правка сцены 3 = новая
  озвучка только сцены 3; остальные из кэша, и сцены после неё кэшируются картинкой (локальное время сцен).
- Сверка текста: `voice.py asr work/voice.wav --text work/script.txt` (платно, копейки;
  gpt-4o-mini-transcribe) ищет проглоченные слова. Принимает и готовый мастер `output/master-rN.mp4`
  (звук вынимается сам); аудиотеги `[confident]` не считаются словами, «60» и «шестьдесят» не пропуск.
  Не доказывает ударение и интонацию.

## Тайминг и текст

- Анимацию текста вешай на слова: `Words('work/voice.words.json', delay=0.4).at('шесть')`.
- Голос в ролике обычно начинается на 0,2–1,2 с (дай картинке вдохнуть); хвост после последнего слова 0,6–1,0 с.
- Числа и бренды пиши так, как их надо произнести («Эйкми Кофи», «девятнадцать тысяч»).
  После предлога «от» и первым словом фразы бренд проглатывается: «в Эйкми Кофи» вместо «от Эйкми Кофи»,
  «Дарим…» вместо «Бренд дарит…».

## Замена слова в готовой озвучке (имя, цифра) — точечно, без новой озвучки целиком

Если голос одним файлом, а поменять нужно одно-два слова (пример: имя героя в 40-секундном мультфильме):
1. Старый голос и тайминги сохранить (`voice.old.wav`, `voice.old.words.json`); в `script.txt` заменить слово и озвучить
   текст заново тем же голосом и темпом — нужен только как донор слова (интонация фразы та же).
2. Из донора вырезать новое слово по его таймингам, подогнать `atempo` под длину старого слота и вклеить в старый
   файл на место старого слова с кроссфейдом 10–15 мс. Всё вне слотов оставить байт в байт старым.
3. `voice.words.json` = старые тайминги с заменённым текстом слова: склейки, ключи и субтитры не сдвигаются,
   `mv.py plan` перерисует только куски с этим словом (в примере 381 кадр из 1218, ~5 мин).
4. Ловушка: у первого слова ролика тайминг ElevenLabs бывает сжат (слот 0,18 с вместо 0,54) — тогда слот брать
   по звуку: от начала речи (порог энергии) до начала следующего слова. Проверять `voice.py asr` готового мастера.
Не перезаписывать всю озвучку: новые тайминги уезжают на +0,6 с и ломают все жёстко заданные склейки.
